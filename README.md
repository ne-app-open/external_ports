# Ports for Ant and NeAnt 🏗️

## Abstract

This repository lets you port software and drivers to NeAnt and Ant.
It's a first step for contributing to Ne.app's suite.

## Guidelines

- The ports Codebase shall use the Ant and NeAnt APIs.
- The ports' UI shall resemble the LWAS UI.
- The ports' Accelerators shall resemble the LWAS UI.
